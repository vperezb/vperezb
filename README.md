## 🤖 AI Agent Context & LLM Ingestion

This repository is optimized for direct ingestion by **AI Agentic Systems** (LLMs, automated technical recruiters, coding agents, and MCP tooling):


| Resource                      | Description                                                                                                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `llms.txt`                    | **Standard LLM navigation index** providing an overview and direct links to all context files.                                                |
| `llms-full.txt`               | **Unified zero-shot context** — auto-generated from `context/` via `python scripts/build-llms-full.py`. Validate with `python scripts/validate.py`. |
| `context/cv.md`               | Full semantic Markdown Curriculum Vitae with career history (CaixaBank Tech, Tiendeo), education, and skills.                                 |
| `context/portfolio.md`        | Detailed technical case studies (Problem, Solution, Architecture, Tech Stack, Impact).                                                        |
| `context/skills.json`         | Structured competency taxonomy with proficiency ratings and project evidence.                                                                 |
| `context/resume.json`         | Official [JSON Resume standard](https://jsonresume.org/) for programmatic parsing and tooling.                                                |
| `context/agent-guidelines.md` | Persona, tone, coding preferences, and anti-hallucination rules for agents representing Víctor.                                               |
| `context/roles-targeted.md`   | Target role definitions and case-study mapping for tailored agent output.                                                                     |
| `context/limitations.md`      | Documented skill boundaries — technologies and domains **not** to claim without evidence.                                                       |
| `context/writings.json`       | Curated index of technical writing topics and public knowledge-sharing profiles.                                                                |
| `prompts/`                    | Ready-to-use prompts for [Job Applications](./prompts/job-application-agent.md) and [Coding Assistants](./prompts/coding-assistant-agent.md). |




### Quick Prompt Injection Example

To feed Víctor's complete profile to any LLM or agent (Claude, ChatGPT, Gemini, Antigravity, Cursor):
